# Bandai_-_Super_Vision_8000

Thumbnails for Bandai Super Vision 8000 games, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the games' MAME short names, as the MAME `sv8000` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
